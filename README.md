# 圖片即譯

把網頁圖片裡的文字辨識出來、翻成你的語言，譯文直接疊回原本的文字位置。針對 X / Twitter 的圖片網址做過處理（自動抓大圖來辨識，準確度差很多）。

OCR 與翻譯都走 Google Gemini API 的免費額度。API 金鑰存在你自己的瀏覽器裡，圖片只送到 Google，沒有任何中間伺服器。

## 安裝

1. 把整個資料夾解壓到一個固定位置（之後不要移動或刪掉）。
2. Chrome 開 `chrome://extensions`。
3. 右上角開啟「開發人員模式」。
4. 點「載入未封裝項目」，選這個資料夾。

## 拿 API 金鑰

1. 到 [Google AI Studio](https://aistudio.google.com/apikey)，用 Google 帳號登入。
2. 按「Create API key」，複製那串 `AIza…`。
3. 點瀏覽器工具列的擴充功能圖示，貼進去，按「儲存設定」。

免費層不用綁信用卡。額度會隨模型和 Google 政策調整，實際上限以 AI Studio 頁面為準；個人手動翻圖幾乎碰不到天花板，但**自動模式跑整條時間軸很容易打到每分鐘上限**。

## 用法

| 動作 | 做法 |
| --- | --- |
| 翻一張圖 | 滑鼠移到圖片上，點圖片角落的小圓鈕「譯」（位置可在設定改，或設為不顯示），或按 `Alt`+`Q` |
| 右鍵翻譯 | 圖片上按右鍵 →「翻譯這張圖片」 |
| 看原文 | 點任何一塊譯文，會切回原文，再點切回來 |
| 收掉譯文 | 再按一次「原圖」，或按 `Esc` 清掉整頁 |
| 自動翻譯 | 擴充功能面板裡的開關，或 `Alt`+`A` |

譯文結果會在該分頁快取，同一張圖不會重複呼叫 API。

快捷鍵想再換，到 `chrome://extensions/shortcuts` 改。注意 `manifest.json` 裡的設定只在第一次安裝時套用，之後改檔案不會生效，一律從這個頁面調。

## 調整

**換模型**：設定面板的「模型」欄位直接填模型名稱。預設 `gemini-3.5-flash-lite`，這是目前最快、最省額度的抽取型模型，適合這種「認字 + 翻譯」的任務。

不要用 `gemini-flash-latest` 或 3.6 / 3.7 Flash——那些是推理型模型，會先思考很久，單張圖可能跑破兩分鐘。準確度只在手寫字或極端排版時才有差別。

Google 會停用舊模型，出現「no longer available」時到 [模型列表](https://ai.google.dev/gemini-api/docs/models) 查目前可用的名稱。

**調翻譯風格**：改 `background.js` 裡的 `prompt()` 函式。例如要保留語氣詞、或指定某種口吻，直接加一行規則進去。

**改譯文外觀**：`content.css` 的 `.imgtr-text`（字色、字重）和 `.imgtr-box`（背景、圓角）。

**自動模式門檻**：設定面板的「最小圖片邊長」，預設 140px，可避免頭像和小圖示被送去翻譯。

## 按了沒反應時

1. 開設定面板按「測試」，會直接告訴你金鑰有沒有問題、模型還在不在。
2. 還是沒反應的話，在頁面上按 F12 開 Console，找 `[圖片即譯]` 開頭的訊息，會顯示請求送出、回傳幾個區塊、或錯在哪。
3. Console 出現「Extension context invalidated」表示你重新載入過擴充功能但分頁還是舊的，重新整理分頁即可。
4. 背景服務的錯誤看 `chrome://extensions` 上這個擴充功能的「Service Worker」連結。

## Google 拒絕處理某些圖片

出現「Google 拒絕處理這張圖」表示圖片被 Google 的 Generative AI 使用政策擋下，發生在伺服器端。這跟程式碼裡的 `safetySettings` 是兩層不同的機制，調整那個參數不會有效果。

分類器有一定誤判率，插畫、迷因、人像照都可能中。確定是誤判的話，只能透過 [Gemini API 的回報管道](https://ai.google.dev/gemini-api/docs/troubleshooting) 反映。

## 已知限制

- 座標由模型推估，密集排版或傾斜文字的位置會有偏移。
- 需要登入才能看的圖片抓不到，會顯示下載失敗。
- SVG 向量圖不支援；超過 6MB 的圖會擋下來。
- X 的燈箱模式（點開大圖）DOM 變動頻繁，偶爾要重新移上去才會出現按鈕。
